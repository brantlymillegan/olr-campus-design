# OLR Campus Design

Interactive campus comparison and school floor plans.

- Compare **Current** and **New**, or view both maps side by side.
- Open **Floor plans** to view either story, a building, or a room.
- Use **Fit to screen** or the **Size** menu to enlarge the drawing.
- Press **T** to switch the active map or floor.
- Explore the **3D** campus in Walking or Flying mode, including furnished rooms, hallways, and stairs in Buildings 1 and 2.
- Adjust the time of day to see daylight, night skies, and the illuminated interiors.

The drawings are a campus planning concept. Room dimensions, floor areas, fixtures, and planning notes are included in the page.

## Hosting

This repository contains a static page published with GitHub Pages. `index.html` includes the drawings and application code; no build step is required. `.nojekyll` preserves the page as static HTML.
